# Suadela — аналитика магазина Галамарт

Откройте `galamart-analyst/index.html` в браузере. Установка, сервер и интернет для работы не нужны; папки `js/`, `lib/` и CSS должны оставаться рядом с HTML.

Новая версия включает медленный сток по 28-дневному отчёту, календарь уценки, экспорт только изменённых цен, исправления начислений 3SKU, сохранения истории и дозаказа зон. Формулы и ограничения описаны в [BUSINESS_RULES.md](docs/BUSINESS_RULES.md).

Стартовый экран — **Vision**. Рабочее место **«Сегодня»**: контроль цен относительно ТН, приоритетные действия, история снимков и цен, план зон, эффективность групп, качество данных и задания сотрудникам с печатью. В подарках доступен множественный выбор КУБов. Инструкция — [DIRECTOR_GUIDE.md](docs/DIRECTOR_GUIDE.md).

В разделе **«К собранию»** можно сформировать печатный отчёт с начала месяца или за последние 7 дней. Число дней и дату среза можно изменить. Для ВП, наценки и сравнения с 2025 годом загрузите «Статистику расширенную» за выбранный период. Дневная динамика ТО и чеков берётся из «План-факта», данные акции — из 3SKU. Недостающие значения, ТОП-100, ПКЗ и 1SKU можно заполнить вручную. Печать и «Сохранить срез» сохраняют значения в браузере для следующих сравнений.

Раздел **«Продажи»**: магазин, группы 1–3, свободные подборки SKU, графики ТО/ВП/возвратов, сценарный прогноз запаса и аналитика переоценок. Инструкция — [SALES_GUIDE.md](docs/SALES_GUIDE.md).

Текущее устройство, границы снимков и обсуждённые предложения следующего этапа — [ARCHITECTURE.md](docs/ARCHITECTURE.md). Предложения не являются уже реализованными изменениями.

Проверки для разработчика требуют Node.js 22.12 или новее. После `npm ci` запустите `npm test` для тестов из `tests/unit/` и `npm run test:browser` для тестов из `tests/browser/`. Для браузерных тестов нужен Chromium, путь к нему можно задать через `CHROME_BIN`. Для запуска приложения npm не нужен.

Документация находится в `docs/`, Excel-отчёт — в `reports/`.

`galamart-analyst/` — исходное офлайн-веб-приложение. Папка `android/` — полноценный Android-проект, который упаковывает его в APK и открывает через защищённый внутренний HTTPS-origin WebView, а не через ненадёжный `file://`.

## Сборка APK

Требования: Android SDK Platform 35, Android Build Tools и JDK 17.

```bash
gradle :app:assembleDebug
```

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Что поддерживает APK

- выбор `.xlsx`, `.xls`, `.csv` и JSON через системный Android file picker;
- все исходные разделы: дашборд, анализ, ТОП-100, проблемы, уценка, просмотр, зоны и подарки;
- раздел **Vision**: дашборд директора магазина с импортом «Статистики расширенной» и «Рейтинга / план-факта», сравнениями, драйвер-анализом и графиками;
- экспорт Excel и сохранение зон через системный Android save dialog;
- локальное хранение настроек и зон внутри приложения;
- полностью офлайн-работа: сеть и доступ WebView к произвольным файлам выключены.

Ассеты `galamart-analyst/` синхронизируются в Android-проект автоматически задачей `:app:syncWebAssets`, которая запускается перед каждой сборкой. Для ручной синхронизации можно выполнить:

```bash
gradle :app:syncWebAssets
```
