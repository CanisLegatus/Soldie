# Suadela — аналитика магазина Галамарт

Откройте `galamart-analyst/index.html` в браузере. Установка, сервер и интернет для работы не нужны; папки `js/`, `lib/` и CSS должны оставаться рядом с HTML. Старые точки входа R29, Suadela и Vision открывают соответствующие разделы единого приложения.

Новая версия включает медленный сток по 28-дневному отчёту, календарь уценки, экспорт только изменённых цен, исправления начислений 3SKU, сохранения истории и дозаказа зон. Формулы и ограничения описаны в [BUSINESS_RULES.md](BUSINESS_RULES.md).

Стартовый экран — **Vision**. Рабочее место **«Сегодня»**: контроль цен относительно ТН, приоритетные действия, история снимков и цен, план зон, эффективность групп, качество данных и задания сотрудникам с печатью. В подарках доступен множественный выбор КУБов. Инструкция — [DIRECTOR_GUIDE.md](DIRECTOR_GUIDE.md).

Проверки для разработчика: `npm ci`, `npm test`, `npm run test:browser` (нужен Chromium; путь можно задать через `CHROME_BIN`). Для работы приложения npm не нужен.

`galamart-analyst/` — исходное офлайн-веб-приложение. Папка `android/` — полноценный Android-проект, который упаковывает его в APK и открывает через защищённый внутренний HTTPS-origin WebView, а не через ненадёжный `file://`.

## Сборка APK

Требования: Android SDK Platform 35, Android Build Tools и JDK 17.

```bash
gradle :app:assembleDebug
```

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Что поддерживает APK

- выбор `.xlsx`, `.xls`, `.csv` и JSON через системный Android file picker;
- все исходные разделы: дашборд, анализ, ТОП-100, проблемы, уценка, просмотр, зоны и подарки;
- раздел **Vision**: дашборд директора магазина с импортом «Статистики расширенной» и «Рейтинга / план-факта», сравнениями, драйвер-анализом и графиками;
- экспорт Excel и сохранение зон через системный Android save dialog;
- локальное хранение настроек и зон внутри приложения;
- полностью офлайн-работа: сеть и доступ WebView к произвольным файлам выключены.

Ассеты `galamart-analyst/` синхронизируются в Android-проект автоматически задачей `:app:syncWebAssets`, которая запускается перед каждой сборкой. Для ручной синхронизации можно выполнить:

```bash
gradle :app:syncWebAssets
```
